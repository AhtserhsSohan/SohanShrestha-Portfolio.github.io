    How I work through the jobs every MSP engineer knows

    Three of the most common tickets in managed services, and the order I check things in. This is how I think on the job.

    "The branch office can't reach the file server"

    Site-to-site VPN down or flapping.

    1. Confirm both sites have internet before blaming the tunnel.
    2. Check tunnel status and logs on the Sophos at each end.
    3. Match phase 1/phase 2 settings and the local/remote subnets.
    4. Test the path and the port from a branch PC, then fix and document.
    # from a branch PC
Test-NetConnection 10.10.0.20 -Port 445
tracert 10.10.0.20

    "New starter on Monday"

    Account, licence, laptop, ready on day one.

    1. Create the user in Entra ID (or AD, synced) and add them to the right groups.
    2. Assign the Microsoft 365 licence and set up the mailbox and Teams.
    3. Enforce MFA before first sign-in.
    4. Enrol the laptop in Intune, check compliance and policies, then hand over.
    # confirm the device is compliant
Intune ▸ Devices ▸ Compliance
# on the laptop
dsregcmd /status

    "Are the backups actually working?"

    Proving recovery before anyone needs it.

    1. Review Datto backup status and alerts for every protected server.
    2. Run a restore test of real files to a safe location.
    3. Confirm the restored data opens and is current.
    4. Record the result so the client has evidence it works.
    # after restoring a test folder
Get-ChildItem D:\RestoreTest -Recurse |
  Measure-Object Length -Sum
